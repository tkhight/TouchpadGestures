# TouchpadGestures 使い方ガイド

Windows のタッチパッドで、**指ごとの動き**を使った独自のジェスチャーを作り、キー操作・ホイール・クリック・ウィンドウ操作・アプリ起動などに割り当てる、常駐アプリです。

- 最終更新: 2026-11-01
- 動作環境: Windows 10 / 11(64 ビット)、Windows Precision Touchpad(PTP)対応のタッチパッド
- 作り: C# / .NET 8 / WinForms

## 1. 概要

- タッチパッド上の**指ごとの位置**を読み取ります(Raw Input / HID)。
- 「3 本指のうち**左の指だけ**が左へスワイプ、中と右は固定」のような、Windows 標準にはないジェスチャーを判定します。
- 判定結果を、キー送信・ホイール・マウスクリック・ウィンドウの移動・アプリ起動などの**動作**に割り当てます。
- 割り当ては JSON ファイルで管理します。JSON を書かずに、**設定画面**から登録・編集もできます。
- 指の位置と判定結果を、画面にリアルタイムで表示します。トレイに常駐できます。

### できることの一覧

| 種類 | 内容 |
|---|---|
| スワイプ | 指ごとに「固定 / 左 / 右 / 上 / 下」を決める。連続発火も可能 |
| タップ | 他の指は触れたまま、1 本だけをタップ(回数も指定可) |
| 同時タップ | 指の本数ぶんを、同時に叩く |
| ピンチ | 全体が閉じる / 開く |
| 着地順 | 指を置く順番(左→中→右 など) |
| 動作 | キー / ホイール / クリック / ドラッグ(押し続ける)/ ウィンドウ移動 / ウィンドウの大きさ変更 / アプリ起動 |
| 条件 | アプリごと / 修飾キーごと / 一時的な無効 / 除外アプリ / 連続発火の抑制 / 削除の保護 |

## 2. はじめ方

### 2-1. 準備(最初に 1 回だけ)

| 必要なもの | 内容 |
|---|---|
| Windows 10 / 11(64 ビット) | Raw Input と WinForms を使うため、Windows のみです |
| .NET 8 SDK | ビルドに必要です。[公式サイト](https://dotnet.microsoft.com/ja-jp/download/dotnet/8.0)から入れます。`dotnet --list-sdks` で `8.0.` で始まる行が出れば完了です |
| PTP 対応のタッチパッド | 「設定」→「Bluetooth とデバイス」→「タッチパッド」に、3 本指・4 本指のジェスチャー欄があれば対応しています。同時タッチ数は 4〜5 本以上あると使いやすいです |
| ソースコード | リポジトリを取得します(`git clone`、または ZIP)。このツールは `TouchpadGestures` フォルダです |

### 2-2. ビルドして起動する

1. ターミナルで `TouchpadGestures` フォルダに移動します。
2. (任意)`dotnet test Gestures.Tests` で、単体テストが全部通ることを確認します。
3. `build_touchpadviewer.bat` を実行します。書き出して、トレイに常駐して起動します。

> `build_touchpadviewer.bat` は、どのフォルダからでも実行できます(ソースの場所は bat 自身の場所から求めます)。書き出し先の既定は `%LOCALAPPDATA%\Programs\TouchpadGestures`(例: `C:\Users\<ユーザー名>\AppData\Local\Programs\TouchpadGestures`)です。別の場所に置きたいときは、引数で指定します(例: `build_touchpadviewer.bat C:\Apps\TouchpadGestures`)。

### 2-3. 使い始める手順

1. **Windows の設定を整える**: このアプリは、OS のタッチパッド処理を止められません。`gestures.json` で使う本数と同じ 3 本指・4 本指の標準ジェスチャーは、Windows の設定で「何もしない」にします。
2. **起動する**: `TouchpadViewer.exe` を起動します。初回は、見本の `gestures.json` が作られます。
3. **動作を確かめる**: 画面に指の本数と座標が出ます。まず、ジェスチャー名が出ることを確認します。
4. **キー送信を入れる**: 「ジェスチャーでキー操作を実行する」にチェックを入れます。**チェックのオン / オフは、次の起動にも引き継がれます**(最初の起動はオフです)。

> キーが送られないときは、まずこのチェックを確認してください。判定と表示は、チェックがオフでも動きます。

### 2-4. 起動の方法

| 方法 | 動き |
|---|---|
| `TouchpadViewer.exe` | 窓を表示して起動 |
| `TouchpadViewer.exe --tray` | 窓を出さず、トレイに常駐して起動 |
| `TouchpadViewer.exe --config <パス>` | 指定した設定ファイルを使う(最優先) |
| 二重起動 | すでに起動していると、既存の窓が前に出る |

- 窓の×ボタンは、終了せずにトレイへ隠します。終了するには、トレイのメニューの「終了」を使います。
- Windows 起動時の自動実行は、トレイのメニューで切り替えます。

## 4. 設定画面で割り当てを登録する

「ジェスチャーを編集…」で開きます。左に割り当ての一覧、右に編集欄があります。編集内容は、**「保存して反映」**を押すまでファイルには書かれません。

### 4-1. 一覧の操作

| 操作 | 説明 |
|---|---|
| アプリで絞り込み | 一覧を、アプリごとに絞ります |
| 追加 / 複製 / 削除 | 割り当てを増やす・コピーする・消す。保護した割り当ては削除できません |
| ↑ ↓ | 並べ替え。順番は動作に影響しません |
| 除外アプリ… | ジェスチャーを実行しないアプリを、1 行に 1 つで編集します |
| 保存して反映 | 全件を検証して保存し、すぐ読み直します。問題があるときは、保存せずに問題点を表示します |
| 閉じる | 並びの変更と除外アプリの変更だけを保存して閉じます。中身の編集は捨てます |

開いたときは、前回選んでいた割り当てから始まります。

### 4-2. 行の色と表示

| 表示 | 意味 |
|---|---|
| 黄色の行 | 編集したが、まだ保存していない |
| 緑の行 | 追加した行 |
| 赤い文字 + 右端に「エラー」 | このままでは保存できない行(重複など)。マウスを重ねると内容が出ます |
| `[保護]` | 保護した行 |
| `(無効)` | 一時的に無効にした行 |

### 4-3. 編集欄

| 項目 | 説明 |
|---|---|
| 名前 | 空欄なら自動で付きます |
| アプリ | 空欄 = 全アプリ共通。プロセス名(`firefox` など)。起動中のアプリが候補に出ます |
| 指の数 | ジェスチャーに使う指の本数 |
| 有効 | オフにすると、その割り当てだけ一時的に無効になります |
| 保護 | チェックを入れると、その割り当ては「削除」できません。編集・複製・並べ替えはできます |
| 修飾キーを押しながら | Ctrl / Alt / Shift / Win を選びます。ちょうどその組み合わせのときだけ有効 |
| 種類 | スワイプ / タップ / ピンチ / 着地順 / 同時タップ |
| 各指の動き | スワイプのとき、左の指から順に、固定 / 左 / 右 / 上 / 下 を選びます |
| 動作 | キー / ホイール / クリック(「ドラッグする」を含む)/ ウィンドウ移動 / ウィンドウの大きさ変更 / アプリ起動 |
| 詳細 | しきい値。空欄 = 既定値。通常は触りません |

> **保存すると、手書きのコメントは消えます。** 元のファイルは `.bak` に残ります。コメントを残したいときは、JSON を直接編集してください。

## 5. ジェスチャーの種類

距離の単位は、すべて「パッド幅 = 1.0」です。

### 5-1. スワイプ

「3 本指のうち、左の指だけが左へ動く。中と右は固定」のように、指ごとに動きを決めます。

- 指は、基準位置を取った瞬間の**左から数えた順**で決まります(0 始まり)。
- JSON では、1 本だけ動かすなら `slot` + `direction`、複数なら `motions` です。
- 動く指が複数のときは、全員が同じ方向(45° 以内)に動くことが条件です。

| しきい値 | 既定 | 意味 |
|---|---|---|
| `minDistance` | 0.06 | 発火に必要な、動く指の移動距離 |
| `fixedTolerance` | 0.03 | 固定の指が動いてよい量 |
| `settleMs` | 0 | 指が揃ってから、基準位置を取るまでの待ち(ミリ秒)。誤発火が多いときは 40 程度に |
| `repeatDistance` | なし | 指定すると、スワイプし続ける間、その距離ごとに連続で発火(音量・スクロール向き) |

### 5-2. タップ

他の指は触れたまま、**1 本だけが着地して離れる**のを 1 回と数えます(例: 2 本を置いて、3 本目をタップ)。

- `tapSlot`: タップする指の位置(左から何番目か)。`tapCount`: 回数(省略 = 1)。
- `maxTapMs`(250)、`maxGapMs`(300)、`maxTapMove`(0.03)で調整できます。
- 2 回タップは、2 回目に離したときに発火します。同じ指に 1 回タップと 2 回タップの両方を割り当てると、1 回タップが先に発火します。

### 5-3. 同時タップ

指の本数ぶんの指が、**ほぼ同時に着地して、ほぼ同時に離れる**動きです(例: 3 本指でポンと叩く)。

- JSON は `{ "fingers": 3, "tapAll": true, "action": { ... } }`。`tapCount` で回数も指定できます。
- 指は 2 本以上です。`maxSpreadMs`(100)が「同時」とみなす幅です。
- Windows 標準の 3 本指タップ(検索・通知)が開くので、Windows の設定で、使う本数のタップを「何もしない」にしてください。

### 5-4. ピンチ

指全体が、閉じる(`In`)/ 開く(`Out`)のを判定します。例: 4 本指のピンチアウト。

- `pinchDistance`(0.05)、`centroidTolerance`(0.10)で調整できます。
- `repeatDistance` を付けると、ズームのような連続発火もできます。

### 5-5. 着地順

「3 本指で、左・中・右の順に置く」のような、**着地の順番**のジェスチャーです。

- `landOrder`: 着地した順に、その指が左から何番目か。左→中→右は `[0, 1, 2]`、右→左→中は `[2, 0, 1]`。
- 最後の指が着地した時点で 1 回だけ発火します。
- `landMinGapMs`(80)、`landMaxGapMs`(500)、`landMaxMove`(0.03)で調整できます。

## 6. 動作の種類

| 種類 | JSON | 説明 |
|---|---|---|
| キー | `"hotkey": "Ctrl+Shift+T"` | キーの組み合わせを押して離す |
| ホイール | `"wheel": 1`(`"horizontal": true` で横) | 1 = 1 ノッチ上 / 右。負の値 = 下 / 左 |
| クリック | `"click": "Left"`(Left / Right / Middle) | 今のカーソル位置でクリック。`"count": 2` でダブル |
| キーを押しながらクリック | `"hotkey": "Win", "click": "Left"` | そのキーを押したままクリック |
| ドラッグ(押し続ける) | `"click": "Left", "hold": true` | 全部の指が離れるまで押し続ける。指の動きでカーソルを動かすので、ドラッグに使える(設定画面では、クリックの「ドラッグする」)。`count` が 2 なら、ダブルタップしてドラッグ。`speed`(速さの倍率。設定画面でも変えられる)。`follow`(指の動きでカーソルを動かす。既定 true)は設定画面には出さず、JSON でだけ指定できる |
| ウィンドウ移動 | `"moveWindow": true`(+ `speed`) | カーソルの下のウィンドウをつかみ、指を離すまで、指の動きに合わせて動かす |
| ウィンドウの大きさ変更 | `"resizeWindow": true`(+ `speed`) | ウィンドウの右下の角を引くように、大きさを変える |
| アプリ起動 | `"run": "C:\\Tools\\a.exe", "args": "--x 1"` | アプリ(や文書・URL)を起動する。`%USERPROFILE%` などの環境変数も使える。`args` は省略可 |

### 補足

- **キー名**: 英数字、`Ctrl` / `Alt` / `Shift` / `Win`、`Enter` / `Esc` / `Tab` / `Space` / `Backspace` / `Delete` など、矢印、ファンクションキー、`VolumeUp` / `VolumeDown` / `VolumeMute`、`MediaPlayPause` など、`Plus` / `Minus`、`NumAdd` などが使えます。設定画面の「キーを押して入力」で、実際にキーを押して取り込めます。
- **速さ(`speed`)**: 指の動きに掛ける倍率で、既定は 1 です。ウィンドウの移動と大きさ変更で共通です。
- ウィンドウの移動・大きさ変更は、最大化したウィンドウ・デスクトップ・タスクバーが対象外です。
- 押し続ける動作は、設定の再読み込み、実行チェックのオフ、アプリの終了で、必ず離します。押してから 60 秒たつと、自動で離します。
- `wheel` は、`hotkey` / `click` と一緒に指定できません。`moveWindow` / `resizeWindow` / `run` は、ほかの動作と一緒に書けません。

## 7. 条件と補助設定

### 7-1. アプリごとの割り当て(`app`)

- プロセス名で指定します(`firefox`、`Code.exe` など。大文字小文字と `.exe` は無視)。名前は、画面のログの `[ ]` で確認できます。
- 省略すると、全アプリ共通になります。
- 前面アプリが取れないとき(管理者権限のアプリなど)は、共通の割り当てだけが働きます。

### 7-2. 修飾キーの条件(`modifiers`)

- `"Ctrl"`、`"Ctrl+Shift"` のように、**ちょうどその組み合わせ**を押しているときだけ有効です。
- `"none"`: どの修飾キーも押していないときだけ。**省略**: 押していても押していなくても有効。
- 条件にした修飾キーは、動作を送る間だけ離して、送り終わったら押し直します。

### 7-3. 一時的に無効にする(`enabled`)

`"enabled": false` で、その割り当てだけ一時的に無効になります。重複の判定には入らないので、同じジェスチャーの別の動作と切り替えて試せます。

### 7-4. 連続発火の抑制(`cooldownMs`)

- `"cooldownMs": 500` のように書くと、その割り当てが動作を実行したあと、500 ミリ秒は、**同じ割り当て**の次の発火を受け付けません。ほかの割り当ては止めません。
- 省略(= 0)なら抑制しません。通常は何も設定せず、連続で発火して困るときだけ付けます。
- `repeatDistance` の連続発火も、この時間で間引かれます。
- 設定画面では、「詳細」のしきい値欄に入力します。

### 7-5. 除外アプリ(`ignoreApps`)

- 設定ファイルの先頭に、`"ignoreApps": ["claunch", "notepad"]` のように書きます。設定画面の「除外アプリ…」でも編集できます。
- ここに書いたアプリが前面のときは、ジェスチャーが成立しても、動作を実行しません。画面の表示とログは通常どおりです。
- 止めるのは、このアプリの動作の実行だけです。タッチパッドの入力そのもの(クリックとして扱われる分など)は、OS が処理するので止められません。

### 7-6. 保護(`protected`)

`"protected": true` の割り当ては、設定画面の「削除」でエラーになります。誤って消さないための印で、動作には影響しません。

### 7-7. 同じジェスチャーが複数あるとき: 優先順位

発火した瞬間の状況に合う割り当てのうち、**条件の多いものが 1 つだけ**動きます。

| 優先 | 条件 |
|---|---|
| 1(最優先) | アプリ + 修飾キー |
| 2 | 修飾キーだけ |
| 3 | アプリだけ |
| 4 | 条件なし |

同じ(アプリ、修飾キー、ジェスチャー)の重複は、設定エラーになります。

## 8. 設定ファイル(gestures.json)

設定ファイルは JSON です。`//` のコメントと、末尾のカンマが使えます。項目名の大文字小文字は区別しません。書き間違い(未知の項目名など)は、全件まとめてエラーになります。

### 8-1. 例

```json
{
  // このアプリが前面のときは、ジェスチャーを実行しない
  "ignoreApps": ["claunch"],
  "bindings": [
    // 3本指・左の指だけが左へ → ブラウザの「戻る」
    { "name": "戻る", "fingers": 3, "slot": 0, "direction": "Left",
      "cooldownMs": 500,
      "action": { "hotkey": "Alt+Left" } },

    // 3本指・中の指だけが上 → 連続でスクロール
    { "fingers": 3, "slot": 1, "direction": "Up", "repeatDistance": 0.03,
      "action": { "wheel": 1 } },

    // 中と右が下、左は固定
    { "fingers": 3, "motions": ["none", "Down", "Down"],
      "action": { "hotkey": "Ctrl+W" } },

    // 3本指・左の指を 2 回タップ(Firefox のときだけ)
    { "app": "firefox", "fingers": 3, "tapSlot": 0, "tapCount": 2,
      "action": { "hotkey": "Ctrl+B" } },

    // 3本指で、同時にタップ
    { "fingers": 3, "tapAll": true,
      "action": { "hotkey": "Win+Tab" } },

    // 4本指のピンチアウト → ズーム(連続)
    { "fingers": 4, "pinch": "Out", "repeatDistance": 0.03,
      "action": { "hotkey": "Ctrl+NumAdd" } },

    // 左→中→右の順に置く
    { "fingers": 3, "landOrder": [0, 1, 2],
      "action": { "hotkey": "Ctrl+Shift+T" } },

    // Ctrl を押しながら 3本指で全員が上 → ウィンドウ最大化
    { "modifiers": "Ctrl", "fingers": 3, "motions": ["Up", "Up", "Up"],
      "action": { "hotkey": "Win+Up" } },

    // 3本指・全員が下 → ウィンドウを、指の動きに合わせて動かす(速さ 1.5 倍)
    { "fingers": 3, "motions": ["Down", "Down", "Down"], "protected": true,
      "action": { "moveWindow": true, "speed": 1.5 } },

    // 3本指・右の指だけが下 → メモ帳を起動
    { "fingers": 3, "slot": 2, "direction": "Down",
      "action": { "run": "notepad" } }
  ]
}
```

### 8-2. 項目の一覧

| 項目 | 説明 |
|---|---|
| `ignoreApps`(ファイルの先頭) | ジェスチャーを実行しないアプリの一覧(`bindings` の外に書く) |
| `name` | 表示名(省略可) |
| `app` | 前面アプリのプロセス名(省略 = 共通) |
| `modifiers` | `"Ctrl"` / `"Ctrl+Shift"` / `"none"`(省略 = 問わない) |
| `enabled` | `false` で無効(省略 = 有効) |
| `cooldownMs` | 実行後に、同じ割り当ての発火を受け付けない時間(ミリ秒)。省略 = 抑制しない |
| `protected` | `true` で、設定画面から削除できない(省略 = 保護しない) |
| `fingers` | 指の本数 |
| `slot` + `direction` | スワイプ(1 本だけ動かす)。`direction` は Left / Right / Up / Down |
| `motions` | スワイプ(左から順に、`none` / Left / Right / Up / Down) |
| `tapSlot` / `tapCount` | タップ |
| `tapAll` / `tapCount` / `maxSpreadMs` | 同時タップ |
| `pinch` / `pinchDistance` / `centroidTolerance` | ピンチ(`"In"` / `"Out"`) |
| `landOrder` / `landMinGapMs` / `landMaxGapMs` / `landMaxMove` | 着地順 |
| `minDistance` / `fixedTolerance` / `settleMs` / `repeatDistance` | スワイプ・ピンチのしきい値 |
| `maxTapMs` / `maxGapMs` / `maxTapMove` | タップ・同時タップのしきい値 |
| `action` | `hotkey` / `wheel`(+ `horizontal`)/ `click`(+ `count` / `hold` / `follow` / `speed`)/ `moveWindow` / `resizeWindow`(+ `speed`)/ `run`(+ `args`) |

手で編集したあとは、「設定を再読み込み」を押します。

## 10. 困ったとき

| 症状 | 確認すること |
|---|---|
| キーが送られない | 「ジェスチャーでキー操作を実行する」のチェック(最初はオフ。前回オフにしたままだと、オフで始まる)。画面にジェスチャー名が出ているか |
| ジェスチャーが反応しにくい | `minDistance` を下げる。画面のログで、固定の指が動いていないか |
| 誤発火が多い | `settleMs` を 40 程度に上げる。`minDistance` を上げる |
| 編集した `gestures.json` が反映されない | 「設定を再読み込み」を押す。使っている設定ファイルの場所が合っているか(「場所を選ぶ…」で確認) |
| Windows 標準のジェスチャーも動いてしまう | Windows の設定で、衝突する 3 本指 / 4 本指のジェスチャーを「何もしない」にする |
| アプリ名を入れても認識されない | ログの `[ ]` の中の名前と、綴りが同じか。管理者権限のアプリなどでは、名前が取れないことがある |
| ランチャーのアイコン上でジェスチャーすると、アイコンが起動する | OS が、パッドの入力をクリックとして扱うため、止められない。アイコンのない場所で行う。動作の実行を止めたいアプリは、除外アプリに入れる |
| 「保存して反映」で保存できない | 一覧の赤い文字の行にマウスを重ねて、内容を見る。同じ条件で、同じジェスチャーが重なっていないか |
| 割り当てを削除できない | 編集欄の「保護」のチェックを外す |
| 押したままの状態が残った | キーを一度押して離す。設定を再読み込みするか、実行のチェックをオフ → オンにする |

---

## 11. 制限

- 最大同時タッチ数は、パッド次第です。
- OS がパッドの入力として処理する分(1〜2 本指のカーソル移動やクリックなど)は、止められません。2 本指のジェスチャーでは、OS の動きが重なることがあります。
- 設定画面で保存すると、手書きのコメントは消えます(`.bak` に元が残ります)。
- 外部ツール(PowerToys の「つかんで移動」など)には、このアプリが送る入力が効かないことがあります。ウィンドウの移動は、`moveWindow` を使ってください。
- ジェスチャーでの「最小化 → 最大化」は、最小化したウィンドウが戻りません。
